# Markov Agent Instructions

## UI and frontend work

For any request involving UI, UX, frontend styling, landing pages, product pages, dashboards, application screens, screenshots, responsive behavior, or visual review, read and apply these repository skills before implementation:

- `.agents/skills/frontend-art-direction/SKILL.md`
- `.agents/skills/product-story-design/SKILL.md` for product-facing and marketing surfaces
- `.agents/skills/markov-interface/SKILL.md` for all Markov interfaces
- `.agents/skills/frontend-visual-qa/SKILL.md` before declaring the work complete

Do not begin a significant UI implementation until an art-direction contract has been written in the working notes. Do not declare a meaningful UI change complete until it has been rendered and reviewed at desktop and mobile sizes.

The design must be derived from Markov's product behavior and real content. Avoid both generic SaaS templates and fashionable “anti-AI-slop” costumes.
