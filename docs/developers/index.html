Request

Start an exploration.

Customer language maps to the V2 job contract. The agent receives inspectable state it can reason over or present for a human decision.

REQUESTPOST /v2/jobs
curl -X POST https://your-markov-host/v2/jobs \
  -H "X-Markov-Key: $MARKOV_API_KEY" \
  -H "Idempotency-Key: japan-demographics-01" \
  -H "Content-Type: application/json" \
  -d '{
    "job": "Explore where it leads",
    "source": {
      "type": "url",
      "value": "https://example.org/source"
    },
    "options": {
      "focus": "second-order market effects",
      "max_connections": 8
    },
    "webhook_url": "https://agent.example/hooks/markov"
  }'
