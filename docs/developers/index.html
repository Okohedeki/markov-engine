Start an exploration.

Use a stable idempotency key for retries. Customer language maps directly to the three V2 jobs.

REQUESTPOST /v2/jobs
curl -X POST https://your-markov-host/v2/jobs \
  -H "X-Markov-Key: $MARKOV_API_KEY" \
  -H "Idempotency-Key: japan-demographics-01" \
  -H "Content-Type: application/json" \
  -d '{
    "job": "Explore where it leads",
    "source": {
      "type": "url",
      "value": "https://example.org/source"
    },
    "options": {
      "focus": "second-order market effects",
      "max_connections": 8
    },
    "webhook_url": "https://agent.example/hooks/markov"
  }'

Structured work, not generated prose in a box.

Each resource keeps its evidence level, score, uncertainty, and link to the case.

Observe

Poll jobs and meaningful events: extraction, claims, evidence, connections, validation, paths, insights, and rendering.

Reason

Read typed connections with endpoints, mechanisms, support, weaknesses, next steps, and reproducible scores.

Continue

Save, dismiss, validate, or follow a connection; convert an insight or artifact without repeating the case.

Core V2 routes

GET  /v2/jobs/{job_id}
GET  /v2/jobs/{job_id}/events
GET  /v2/cases/{case_id}
GET  /v2/cases/{case_id}/connections
GET  /v2/cases/{case_id}/paths
GET  /v2/cases/{case_id}/insights
POST /v2/connections/{connection_id}/validate
POST /v2/connections/{connection_id}/decisions
POST /v2/connections/{connection_id}/follow
POST /v2/insights/{insight_id}/convert
POST /v2/artifacts/{artifact_id}/convert

API access is entitlement-controlled. Citation quality, uncertainty labels, source packets, and accuracy checks are not.
