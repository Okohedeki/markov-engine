# Markov — soft studio

Current UI direction, 2026-09-05. Replaces V10's visual treatment, not its
customer, working features, or integration boundaries.

## Art-direction contract

- Audience: frequent posters, creators, social teams, and agencies who need
  many distinct ideas from the conversations they follow.
- Task: conversation → different angles → shortlist → editable outline.
- Thesis: a calm, dimensional idea studio. Cool light, rounded typography,
  tactile controls, and white writing surfaces make the content feel inviting.
- Memory hook: one conversation fans into three different hooks, then becomes
  an outline. The public demo shows this transformation, not a whole dashboard.
- Composition: a compact floating navigation capsule above a dark-to-blue
  opening; a centered promise; a softly elevated product scene. A charcoal
  section provides contrast. The actual studio is an open working canvas with
  a horizontal conversation selector, not a sidebar and pastel tile matrix.
- Type: self-hosted DM Sans, moderate headline scale, readable body text and
  controls. Strong hierarchy comes from space and weight, not giant type.
- Palette/material: porcelain, cool gray, ink, restrained orange. White paper
  surfaces, subtle outlines and layered shadows. The bounded blue opening is
  intentional reference-derived material, not an incidental AI glow effect.
- Interaction: tactile segmented controls with meaningful state changes;
  keyboard-operable demo tabs; reversible saved ideas; editable native dialog.
  No auto-cycling scenes or decorative continuous motion.
- Forbidden: alternating pastel cards, decorative metrics, fake social proof,
  fake live discussion feeds, tiny labels, feature-tile boilerplate, glass UI.

## Reference translation

1. Recall, https://www.recall.it/?utm_source=chatgpt.com — inspected rendered in
   Chrome, not only its crawler text. Borrow the compact white capsule nav,
   black/blue/white opening, soft dimensional product surfaces and focused
   segmented demonstrations. Do not copy its logo, assets or product claims.
2. Vitsœ / Dieter Rams, https://www.vitsoe.com/us/about/good-design — physical
   product reference: clearly understandable controls, useful restraint, and
   care for details that let the user's content take the foreground.
3. W3C tabs pattern, https://www.w3.org/WAI/ARIA/apg/patterns/tabs/ — a single
   active scene, associated tab/panel semantics, roving focus, arrow/Home/End
   navigation. All scene content is already available, so activation is instant.

## Product honesty and preservation

The example contains prewritten sample conversations and outlines, explicitly
labelled. Saving, editing, copying, and exporting really work locally. Keep the
authenticated engine's source submission, results, drafts, account and credits.
Live discovery, batch AI generation, scheduling and social publishing are not
implemented by this UI task. No backend or unrelated user work is deleted.

Verify rendered desktop, tablet and mobile; test topic selection, demo tabs,
shortlists, persistence, editor focus, copy/export, navigation, errors and
reduced motion. Export the same design to the existing static site.
