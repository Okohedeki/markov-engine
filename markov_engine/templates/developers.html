Markov for agents

Send one research job. Keep the whole trail.

The API exposes the same case people inspect in the workspace: stable job state, claims, evidence passages, typed connections, artifacts, costs, and review events.

Open API reference ↗

The contract

A finished artifact and the state required to audit or continue it.

  1. 01

    Submit a source or question

    Use one idempotent asynchronous job for a brief, research report, or factual script.

  2. 02

    Observe useful stages

    Follow source reading, claim mapping, evidence checks, connection validation, and artifact creation.

  3. 03

    Retrieve inspectable state

    Exact passages, locators, stance, uncertainty, and user branch decisions stay addressable.

  4. 04

    Continue the same case

    Convert outputs or follow a connection without repeating unchanged extraction and research.

Request

Start an exploration.

POST /v2/jobs
curl -X POST {{ api_docs_url | replace('/docs', '') }}/v2/jobs \
  -H "X-Markov-Key: $MARKOV_KEY" \
  -H "Idempotency-Key: japan-brief-1" \
  -H "Content-Type: application/json" \
  -d '{
    "job": "Explore where it leads",
    "review_level": "instant",
    "source": {
      "type": "url",
      "value": "https://www.youtube.com/watch?v=..."
    },
    "options": {"focus": "capital-flow mechanism"}
  }'
