Agent contract

Structured opportunity data—not generated prose in a box.

Every resource keeps its evidence level, ranking dimension, uncertainty, decision history, and link to the originating case.

01

Signal in

Pass a source, observation, question, topic, or existing brief with stable idempotency for safe retries.

02

Opportunity out

Read claims, landscape coverage, typed connections, mechanisms, weaknesses, and separate information-gain and audience-relevance signals.

03

Decision retained

Save, dismiss, validate, investigate, or develop a direction while keeping the evidence boundary attached.

Request

Start an exploration.

Customer language maps to the V2 job contract. The agent receives inspectable state it can reason over or present for a human decision.

REQUESTPOST /v2/jobs
curl -X POST https://your-markov-host/v2/jobs \
  -H "X-Markov-Key: $MARKOV_API_KEY" \
  -H "Idempotency-Key: japan-demographics-01" \
  -H "Content-Type: application/json" \
  -d '{
    "job": "Explore where it leads",
    "source": {
      "type": "url",
      "value": "https://example.org/source"
    },
    "options": {
      "focus": "second-order market effects",
      "max_connections": 8
    },
    "webhook_url": "https://agent.example/hooks/markov"
  }'
